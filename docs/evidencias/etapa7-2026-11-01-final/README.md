# Evidências visuais da etapa 7 — 1º de novembro de 2026

Esta galeria reúne **30 capturas** da prévia Flutter Web em modo demonstração, com dados fictícios. Foram registradas a Home, a Busca, o perfil profissional privado, a agenda e a moderação de documentos, em larguras lógicas de **360, 390 e 412 px**, com texto em **100% e 200%**. Cada imagem mostra a área inicial de uma tela com altura lógica de 844 px.

As 24 capturas de Home, Busca, perfil e agenda foram produzidas após o commit `8f1a1d4`. As seis capturas de documentos foram atualizadas após `db635f2`. O arquivo [capturas.json](capturas.json) lista as 30 imagens; [capturas-admin-atualizadas.json](capturas-admin-atualizadas.json) registra a rodada mais recente do admin. Os dois registros apontam **zero exceções no navegador**.

Exemplos para revisão: [Home em 360 px](home-360.png), [Busca em 360 px com texto a 200%](busca-200-360.png), [perfil em 360 px com texto a 200%](perfil-profissional-privado-200-360.png), [agenda em 412 px com texto a 200%](agenda-200-412.png) e [documentos em 390 px com texto a 200%](admin-documentos-200-390.png). Essas cinco imagens foram inspecionadas visualmente; as demais foram geradas e registradas, sem revisão visual individual.

Esta evidência cobre a prévia com dados simulados. A homologação em aparelho Android, com TalkBack, teclado nativo, seletor de arquivos e API real, continua pendente.
